¿Cómo identifico las variables de un fenómeno?

Todo fenómeno que observas esconde relaciones entre cantidades que cambian. Aprende a descubrirlas haciéndote tres preguntas sencillas.

🔍🌱🧪
Para empezar

Ponte en el papel de quien experimenta

Imagina que tú vas a realizar el experimento. Toca cada tarjeta para descubrir qué variable esconde cada pregunta.

①

¿Qué puedo cambiar intencionalmente?

Toca para descubrir
Variable independiente

Es la cantidad que tú decides modificar para observar qué ocurre.

②

¿Qué cambia como consecuencia?

Toca para descubrir
Variable dependiente

Es la cantidad que observas o mides después de cambiar la variable independiente.

③

¿Qué debo mantener igual?

Toca para descubrir
Variables controladas

Condiciones que podrían afectar el resultado, pero se mantienen constantes para que la comparación sea justa.

🧪 Experimenta tú mismo

Ejemplo: el resorte

Cuelga distintas masas del mismo resorte y observa qué pasa.

150 gLo que yo cambio
3.8 cmLo que se observa
🔒 El resorte y el soporte — no cambian en todo el experimento.

Independiente

La masa que cuelgo.

Dependiente

Cuánto se alarga el resorte.

Controladas

Resorte, soporte y condiciones.

🧠 Recuerda
Cambio → Respuesta → Condiciones constantes

No memorices solamente los nombres. Primero piensa en lo que ocurre en el experimento y después identifica cada variable.

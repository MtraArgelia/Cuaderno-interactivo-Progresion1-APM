¿Qué ocurre con una variable cuando cambia la otra?
Tres formas de relación

Toca cada caso para ver el ejemplo

📈 Caso 1 · Las dos aumentan

Si al aumentar X también aumenta Y, existe una relación creciente.

Ejemplo: a mayor fuerza aplicada a un resorte → mayor alargamiento.
Toca para ver el ejemplo

📉 Caso 2 · Una sube, la otra baja

Si al aumentar X disminuye Y, existe una relación decreciente.

Ejemplo: a mayor velocidad de un vehículo → menor tiempo para recorrer una distancia.
Toca para ver el ejemplo

🌀 Caso 3 · Aumentan, pero no igual

Y aumenta cuando X aumenta, pero el cambio no mantiene el mismo patrón.

Ejemplo: en una caída libre, la distancia recorrida aumenta cada vez más rápido conforme pasa el tiempo.
